# Required Book

* There is no required textbook for OMIS 105. 
* All course materials — lectures, labs, installation guides, and reference documents — are available in [the course repository](https://github.com/mahmoudparsian/OMIS-105)

* For deeper practice, the recommended (optional) reading is [*DuckDB in Action*](https://github.com/mahmoudparsian/OMIS-105/blob/main/books/DuckDB_In_Action_Final_BOOK_2024.PDF), available in the `books/` folder of the repository.
