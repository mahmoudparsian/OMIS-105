# OMIS 105 — In-Class Lab Policies

**Course:** OMIS 105 — Introduction to Database Management Systems  
**Quarter:** Fall 2026  

---

## ☑️ 1. Weekly Lab Structure

✅ Each class period includes a **lab-in-class** session.

✅ You have to complete the lab in-class.
  
✅ **One Marimo notebook lab** per class session

For example, the labs for **Week 01** are:

###  🗓️ Labs for Tuesday Class

- `week01_lab_01_student.py`

###  🗓️ Labs for Thursday Class

- `week01_lab_02_student.py`

#### ✅ Labs will be available after 45 minutes of lecture by your instructor

---

##  ☑️ 2. Lab Format

All labs are provided as **Marimo Notebooks (`.py`)**.

Students are expected to:

- Open the notebook in Marimo
- Complete all required exercises
- Execute all cells before submission

---

## ☑️ 3. Lab Completion and Submission

Labs must:

- Be started during the scheduled class session
- Be completed during the same class session
- Be submitted before the end of class

Late or incomplete submissions may receive reduced 
credit unless otherwise approved by the instructor.

---

## ☑️ 4. Instructor Assistance

Students are encouraged to ask questions during class.

The instructor will be available to:

- Clarify concepts
- Help debug code
- Assist with SQL, Python, DuckDB, or notebook issues
- Provide guidance during lab activities

However, students are expected to complete and submit their own work.

---

## ☑️ 5. File Naming Convention for Submission

Students must rename their notebook files before 
submission using the following format:

```text
week##_lab_##_firstname_lastname.py
```

For example, if your name is **Jane Smith**, 
your submitted files for Week 01 would 
be (**your file name must be in lowercase 
characters**).

* Tuesday Class
	* `week01_lab_01_jane_smith.py`

* Thursday Class
	* `week01_lab_02_jane_smith.py`

---

## ☑️ 6. Academic Integrity

Students may discuss concepts and ask questions 
during class, but all submitted work must represent 
the student’s own effort.

Copying another student’s notebook or submitting 
duplicated work is not permitted.

---

## ☑️ 7. Technical Recommendations

Students should:

* Bring a fully charged laptop to class (see
  [`LAPTOP.md`](./LAPTOP.md))
* Install all required software before class
* Regularly save their notebooks during lab sessions
* Keep backup copies of submitted work

Recommended tools include:

* Python (3.10+)
* DuckDB
* Marimo Notebook
* Pandas
* qStudio (SQL editor)
* VS Code or a similar text editor
