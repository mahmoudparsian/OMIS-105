# Bonus Week 13 Review — Query Performance

📦 **[Download this bonus week as a ZIP](https://github.com/mahmoudparsian/OMIS-105/releases/download/weekly-zips/bonus-week13-query-performance.zip)** — this week's lectures and review, in one file. No git needed.

An optional bonus week: see what the database actually does with your query, and how to help it go faster. Indexing is a senior-level topic — it is not part of the ten required weeks.

## Run It

```bash
cd weekly_reviews/bonus/week13-query-performance
marimo edit week13_review_notebook.py
```

Run the command from inside this folder. The notebook creates all of its
data inline, so it works from anywhere, but Marimo is easiest to launch
from here.

This notebook is self-contained: it rebuilds every table it needs. You do not have to run any other week first.
