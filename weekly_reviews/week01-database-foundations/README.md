# Week 1 Review — Querying a Single Table

Ask one flat table the questions a manager would actually ask.

## Run It

```bash
cd weekly_reviews/week01-database-foundations
marimo edit week01_review_notebook.py
```

Run the command from inside this folder. The notebook resolves its data
directory relative to its own location, so it works from anywhere, but
Marimo is easiest to launch from here.

## Files

| File | Purpose |
|------|---------|
| `week01_review_notebook.py` | The review notebook — open this in Marimo |
| `week01_review_notes.md` | Teaching notes: timing, discussion prompts, homework |
| `data/orders_data.csv` | The dataset (20 retail orders) |

## SQL Covered

`SELECT`, `WHERE`, `AND`/`OR`, `IN`, `BETWEEN`, `LIKE`, `ORDER BY`, `LIMIT`, `DISTINCT`, `COUNT`

## Dataset

`data/orders_data.csv` — 20 retail orders (6 customers, 6 products, 3 categories), loaded as one flat table.
