# Weekly Reviews

Cumulative review notebooks and lecture notes for
**OMIS 105 — Introduction to Database Management Systems**.

These materials consolidate each set of three weeks into a
single comprehensive notebook and accompanying lecture notes.
Use them for review sessions, exam preparation, or as a
reference during later weeks.

## Files in This Folder

| File | Description |
|------|-------------|
| `weeks_1_3_notebook.py` | Marimo notebook covering Weeks 1–3: SELECT, WHERE, ORDER BY, LIMIT, DISTINCT, normalization, JOINs (INNER, LEFT), GROUP BY, HAVING, subqueries, plus plots |
| `weeks_1_3_lecture_notes.md` | Lecture-by-lecture teaching plan (6 lectures × 2 hours) with discussion points and homework |
| `weeks_4_6_notebook.py` | Marimo notebook covering Weeks 4–6: window functions, ranking, LAG/LEAD, running totals, CASE, CTEs, FULL OUTER JOIN, CROSS JOIN, SELF JOIN, normalization (1NF/2NF/3NF), constraints, views |
| `weeks_4_6_lecture_notes.md` | Lecture notes for Weeks 4–6 with discussion guides |
| `orders_data.csv` | 20-row retail orders dataset (6 customers, 6 products, 3 categories) — used by Weeks 1–3 notebook |
| `company_data.csv` | 30-row tech company dataset (30 employees, 5 departments) — used by Weeks 4–6 notebook |
| `plot_helpers.py` | Matplotlib plotting functions (plot_bar, plot_hbar, plot_pie, plot_grouped_bar) |
| `marimo_template.py` | Marimo notebook template |

## Tech Stack

- **Database:** DuckDB (in-memory)
- **Notebooks:** Marimo (reactive Python notebooks)
- **Language:** Python 3 + SQL
