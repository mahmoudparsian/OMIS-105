# Week 10 Review — Modern DuckDB — JSON, PIVOT & Lists

Real-world data shapes — JSON columns, pivoting for reports, and lists — plus a look back at the whole course.

## Run It

```bash
cd weekly_reviews/week10-review-modern-data
marimo edit week10_review_notebook.py
```

Run the command from inside this folder. The notebook resolves its data
directory relative to its own location, so it works from anywhere, but
Marimo is easiest to launch from here.

This notebook is self-contained: it rebuilds every table it needs. You do not have to run Week 9 first.
