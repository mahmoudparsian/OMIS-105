# Marimo for Labs

Two bulletproof, OS-specific walkthroughs covering the two things that
trip up students most before a lab even starts:

| File | Covers |
|---|---|
| [`running_marimo_on_macbook.md`](running_marimo_on_macbook.md) | Opening a Marimo notebook from Terminal, and DuckDB `:memory:` vs. persistent (file) connections, with Mac path examples |
| [`running_marimo_on_windows.md`](running_marimo_on_windows.md) | Opening a Marimo notebook from Command Prompt, and DuckDB `:memory:` vs. persistent (file) connections, with Windows path examples — including the backslash-vs-forward-slash problem |
| [`week_01_lab_02_sample.py`](week_01_lab_02_sample.py) | The sample notebook both walkthroughs above tell you to copy and run — confirms Marimo + DuckDB work, and lets you try `:memory:` vs. persistent yourself |

Pick the file matching your laptop. Each one is self-contained — you
don't need to read the other. Both point you to `week_01_lab_02_sample.py` as
the notebook to copy into your own `OMIS-105-LABS` folder and run.
