# Marimo Docs and Tutorials

## Notebooks in This Folder

- **`marimo_101_duckdb_sql.py`** — Start here if you've never used
  Marimo before. A beginner-friendly notebook that introduces cells,
  reactivity, and UI elements, then uses DuckDB/SQL (`CREATE TABLE`,
  `INSERT`, `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, and an
  interactive dropdown filter) on a small campus-bookstore dataset.
  Run it with `marimo edit marimo_101_duckdb_sql.py`.
- **`marimo_introduction.py`** — Marimo's own official tour of the
  editor (reactivity, UI elements, running notebooks as apps, keyboard
  shortcuts). No SQL — pure Marimo mechanics.
