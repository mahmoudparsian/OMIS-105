# DuckDB RANK Function


	Summary: in this tutorial, you will learn 
	about the RANK() function and how 
	to apply it to assign a rank to each row 
	within the partition of a result set.

	All examples run in DuckDB.

## Introduction to the RANK() function

	The RANK() function assigns a rank to 
	each row within the  partition  of a 
	result set.   The rank  of a  row is 
	specified by one plus the number of 
	rows that come before it.

The following shows the syntax of the RANK() function:

```sql no-run
RANK() OVER (
    PARTITION BY <expression>[{,<expression>...}]
    ORDER BY <expression> [ASC|DESC], [{,<expression>...}]
)
```


	1. the PARTITION BY clause divides the 
	   result sets into partitions. The RANK() 
	   function is performed within partitions 
	   and re-initialized when crossing the 
	   partition boundary.

	2. The ORDER BY clause sorts the rows 
	   within a partition by one or more columns 
	   or expressions.

	3. Unlike the ROW_NUMBER() function, the 
	   RANK() function does not always return 
	   consecutive integers.

Suppose you have a sample table as follows:

```sql
CREATE OR REPLACE TABLE t (
    val INTEGER
);
```

Then insert some rows:

```sql
INSERT INTO t(val)
VALUES (1), (2), (2), (3), (4), (4), (5);
```

Show table content:

```sql
SELECT * FROM t;
```

<!-- RESULT -->

| val |
|----:|
|   1 |
|   2 |
|   2 |
|   3 |
|   4 |
|   4 |
|   5 |

*(7 rows)*

<!-- /RESULT -->


	The following statement uses the RANK() 
	function to assign a rank to each row 
	from the result set in the t table:

```sql
SELECT
    val,
    RANK() OVER (
        ORDER BY val
    ) AS my_rank
FROM
    t
ORDER BY
    val;
```

Here is the output:

<!-- RESULT -->

| val | my_rank |
|----:|--------:|
|   1 |       1 |
|   2 |       2 |
|   2 |       2 |
|   3 |       4 |
|   4 |       5 |
|   4 |       5 |
|   5 |       7 |

*(7 rows)*

<!-- /RESULT -->

	NOTES:
	
		1. The output indicates that the second 
		   and third rows have the same ties so 
		   they receive the same rank 2.

		2. The fourth row has rank 4 because the 
		   RANK() function skips the rank 3.

## Example:

```sql
SELECT
      val,
      RANK()       OVER (ORDER BY val) AS the_rank,
      DENSE_RANK() OVER (ORDER BY val) AS the_dense_rank,
      ROW_NUMBER() OVER (ORDER BY val) AS the_row_number
FROM
      t
ORDER BY
      the_row_number;
```

<!-- RESULT -->

| val | the_rank | the_dense_rank | the_row_number |
|----:|---------:|---------------:|---------------:|
|   1 |        1 |              1 |              1 |
|   2 |        2 |              2 |              2 |
|   2 |        2 |              2 |              3 |
|   3 |        4 |              3 |              4 |
|   4 |        5 |              4 |              5 |
|   4 |        5 |              4 |              6 |
|   5 |        7 |              5 |              7 |

*(7 rows)*

<!-- /RESULT -->


## RANK() function example

	Let’s use a sales table for the demonstration.

Here is the script to create the sales table:

```sql
CREATE OR REPLACE TABLE sales(
    sales_employee VARCHAR NOT NULL,
    fiscal_year    INTEGER NOT NULL,
    sale           DECIMAL(14,2) NOT NULL,
    PRIMARY KEY(sales_employee, fiscal_year)
);
```

Insert some rows:

```sql
INSERT INTO sales(sales_employee, fiscal_year, sale)
VALUES('Bob',   2016, 100),
      ('Bob',   2017, 150),
      ('Bob',   2018, 200),
      ('Alice', 2016, 150),
      ('Alice', 2017, 100),
      ('Alice', 2018, 200),
      ('John',  2016, 200),
      ('John',  2017, 150),
      ('John',  2018, 250);
```

Show table content:

```sql
SELECT * 
FROM sales
ORDER BY sales_employee, fiscal_year;
```

<!-- RESULT -->

| sales_employee | fiscal_year |   sale |
|----------------|------------:|-------:|
| Alice          |        2016 | 150.00 |
| Alice          |        2017 | 100.00 |
| Alice          |        2018 | 200.00 |
| Bob            |        2016 | 100.00 |
| Bob            |        2017 | 150.00 |
| Bob            |        2018 | 200.00 |
| John           |        2016 | 200.00 |
| John           |        2017 | 150.00 |
| John           |        2018 | 250.00 |

*(9 rows)*

<!-- /RESULT -->

	The following statement uses the RANK() 
	function to rank the sales employees by 
	sales amount every year:

```sql
SELECT
    sales_employee,
    fiscal_year,
    sale,
    RANK() OVER (PARTITION BY
                     fiscal_year
                 ORDER BY
                     sale DESC
                ) AS sales_rank
FROM
    sales
ORDER BY
    fiscal_year, sales_rank, sales_employee;
```

Output:

<!-- RESULT -->

| sales_employee | fiscal_year |   sale | sales_rank |
|----------------|------------:|-------:|-----------:|
| John           |        2016 | 200.00 |          1 |
| Alice          |        2016 | 150.00 |          2 |
| Bob            |        2016 | 100.00 |          3 |
| Bob            |        2017 | 150.00 |          1 |
| John           |        2017 | 150.00 |          1 |
| Alice          |        2017 | 100.00 |          3 |
| John           |        2018 | 250.00 |          1 |
| Alice          |        2018 | 200.00 |          2 |
| Bob            |        2018 | 200.00 |          2 |

*(9 rows)*

<!-- /RESULT -->

In this example:

	1. the PARTITION BY clause breaks 
	   the result sets into partitions 
	   by fiscal year.

	2. Then, the ORDER BY clause sorts 
	   the sales employees by sales in 
	   descending order.

	3. The last ORDER BY (outside OVER) 
	   only sorts the output for display.


## Find top performer employee per year

```sql
WITH RANKED_SALES AS
(
  SELECT
    sales_employee,
    fiscal_year,
    sale,
    RANK() OVER (PARTITION BY
                     fiscal_year
                 ORDER BY
                     sale DESC
                ) AS sales_rank
  FROM
    sales
)
SELECT sales_employee,
       fiscal_year,
       sale,
       sales_rank
FROM RANKED_SALES
WHERE sales_rank = 1
ORDER BY fiscal_year, sales_employee;
```

<!-- RESULT -->

| sales_employee | fiscal_year |   sale | sales_rank |
|----------------|------------:|-------:|-----------:|
| John           |        2016 | 200.00 |          1 |
| Bob            |        2017 | 150.00 |          1 |
| John           |        2017 | 150.00 |          1 |
| John           |        2018 | 250.00 |          1 |

*(4 rows)*

<!-- /RESULT -->

## Find bottom performer employee per year

```sql
WITH RANKED_SALES AS
```

## The same query with `QUALIFY` (DuckDB)

	DuckDB has a QUALIFY clause: it filters on a 
	window function, the way HAVING filters on an 
	aggregate. So the top performers per year can 
	be found without a CTE:

```sql
SELECT
    sales_employee,
    fiscal_year,
    sale,
    RANK() OVER (PARTITION BY fiscal_year
                 ORDER BY sale DESC) AS sales_rank
FROM
    sales
QUALIFY sales_rank = 1
ORDER BY fiscal_year, sales_employee;
```

<!-- RESULT -->

| sales_employee | fiscal_year |   sale | sales_rank |
|----------------|------------:|-------:|-----------:|
| John           |        2016 | 200.00 |          1 |
| Bob            |        2017 | 150.00 |          1 |
| John           |        2017 | 150.00 |          1 |
| John           |        2018 | 250.00 |          1 |

*(4 rows)*

<!-- /RESULT -->

	Both ways give the same answer. The CTE way 
	works in every database; QUALIFY is shorter.


## RANK() function with CTE example

	The following statement uses the RANK() 
	function to find the top three highest 
	valued order lines in each year.

	It uses two small tables, orders and 
	orderdetails (one order has one or more 
	order lines):

```sql
CREATE OR REPLACE TABLE orders (
    orderNumber INTEGER PRIMARY KEY,
    orderDate   DATE NOT NULL
);

INSERT INTO orders VALUES
(10100, DATE '2003-01-06'),
(10101, DATE '2003-03-09'),
(10102, DATE '2003-07-10'),
(10200, DATE '2004-02-02'),
(10201, DATE '2004-06-15'),
(10300, DATE '2005-01-20'),
(10301, DATE '2005-04-11');

CREATE OR REPLACE TABLE orderdetails (
    orderNumber     INTEGER,
    productCode     VARCHAR,
    quantityOrdered INTEGER,
    priceEach       DECIMAL(10,2),
    PRIMARY KEY (orderNumber, productCode)
);

INSERT INTO orderdetails VALUES
(10100, 'S10_1678', 30, 95.70),
(10100, 'S12_1099', 50, 55.09),
(10101, 'S18_2248', 25, 108.06),
(10102, 'S10_1678', 41, 81.35),
(10102, 'S24_3856', 39, 86.30),
(10200, 'S12_1099', 45, 120.00),
(10200, 'S18_2248', 20, 99.10),
(10201, 'S24_3856', 60, 70.15),
(10201, 'S10_1678', 22, 60.00),
(10300, 'S12_1099', 34, 150.00),
(10301, 'S18_2248', 49, 101.50),
(10301, 'S24_3856', 15, 80.00);
```

Now rank the order lines of each year by their value:

```sql
WITH order_values AS(
    SELECT 
        orderNumber, 
        YEAR(orderDate) AS order_year,
        quantityOrdered * priceEach AS order_value,
        RANK() OVER (
            PARTITION BY YEAR(orderDate)
            ORDER BY quantityOrdered * priceEach DESC
        ) AS order_value_rank
    FROM
        orders
    INNER JOIN orderdetails USING (orderNumber)
)
SELECT 
    * 
FROM 
    order_values
WHERE 
    order_value_rank <= 3
ORDER BY
    order_year, order_value_rank;
```

Here is the output:

<!-- RESULT -->

| orderNumber | order_year | order_value | order_value_rank |
|------------:|-----------:|------------:|-----------------:|
|       10102 |       2003 |     3365.70 |                1 |
|       10102 |       2003 |     3335.35 |                2 |
|       10100 |       2003 |     2871.00 |                3 |
|       10200 |       2004 |     5400.00 |                1 |
|       10201 |       2004 |     4209.00 |                2 |
|       10200 |       2004 |     1982.00 |                3 |
|       10300 |       2005 |     5100.00 |                1 |
|       10301 |       2005 |     4973.50 |                2 |
|       10301 |       2005 |     1200.00 |                3 |

*(9 rows)*

<!-- /RESULT -->

In this example:

	1. use a common table expression (CTE) 
	   to get the order number, order year, 
	   and rank. To rank orders by order value 
	   in each year, we used the RANK() function 
	   that partitioned the rows by order year 
	   and sorted the order value in descending order.

	2. Then, select only the orders whose rank is 
	   less than or equal to three.

	3. 2004 has only 4 order lines and 2005 has 
	   only 3, so 2005 shows all of its lines.

## Summary

	Use the RANK() function to assign 
	a rank to each row in a result set.
