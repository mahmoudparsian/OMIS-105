# Create a DuckDB Database from SQL Files

Build a saved/persistent DuckDB database file (`my_database.duckdb`) from two SQL
files: 

* `db_schema.sql` (the tables) and
* `db_records.sql` (the records/rows).

**Choose the guide for your computer:**

- [macOS guide](create_duckdb_database_from_SQL_files_on_macbook.md)
- [Windows guide](create_duckdb_database_from_SQL_files_on_windows.md)

Each guide is complete on its own. Follow only the guide for your computer.

**Practice files in this folder:**

| File | What it contains |
|---|---|
| [db_schema.sql](db_schema.sql) | 2 tables: `departments` and `employees` (with a foreign key) |
| [db_records.sql](db_records.sql) | 3 departments and 6 employees |

Download the whole folder so the guides and the SQL files stay together.
