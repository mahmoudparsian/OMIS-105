# DuckDB from the Command Line

Two OS-specific slide decks covering the DuckDB CLI — a separate,
standalone `duckdb` program you run directly in a terminal, with no
Python or Marimo involved.

| File | Covers |
|---|---|
| [`duckdb_from_command_line_on_macbook.md`](duckdb_from_command_line_on_macbook.md) ([PDF](duckdb_from_command_line_on_macbook.pdf)) | Installing the CLI on macOS (Homebrew or manual download), Apple Silicon vs. Intel, Gatekeeper, dot-commands, `.mode`, reading CSVs, script files |
| [`duckdb_from_command_line_on_windows.md`](duckdb_from_command_line_on_windows.md) ([PDF](duckdb_from_command_line_on_windows.pdf)) | Installing the CLI on Windows (`winget` or manual download), PATH setup, SmartScreen, Command Prompt vs. PowerShell quoting, dot-commands, `.mode`, reading CSVs, script files |
| [`data/students.csv`](data/students.csv) | The sample file both decks query |

Pick the deck matching your laptop. Each one is self-contained — you
don't need to read the other.
