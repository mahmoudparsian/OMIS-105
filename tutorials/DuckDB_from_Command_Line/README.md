# DuckDB from the Command Line

Learn to run DuckDB in a terminal, query a CSV file, and save your work.
No Python or Marimo is needed.

**Choose the guide for your computer:**

- [macOS guide](duckdb_from_command_line_on_macbook.md)
  
- [Windows guide](duckdb_from_command_line_on_windows.md)

Each guide includes installation, practice, and troubleshooting. Follow only
the guide for your computer.

Download the whole folder, including [data/students.csv](data/students.csv)
(8 students plus a header).
