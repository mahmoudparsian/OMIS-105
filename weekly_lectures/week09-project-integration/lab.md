# Week 9 Project

## Build Your Own Database

### Requirements:
- Minimum 3 tables
- Define primary and foreign keys
- Insert at least 10 rows per table
- Write 5 queries:
  1. Basic SELECT
  2. WHERE filter
  3. JOIN
  4. GROUP BY
  5. Analytical query

### Deliver:
- SQL file
- Output screenshots
- 1-page explanation
