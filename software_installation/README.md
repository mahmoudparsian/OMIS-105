## Choose Your Operating System

This folder has two completely separate, self-contained guides — one
for each operating system. Pick the one that matches your computer and
follow **only that folder** from here on; you won't need to open the
other one.

| Operating system | Go to |
|-------------------|-------|
| **Mac** | [`macbook/README.md`](macbook/README.md) |
| **Windows** | [`windows/README.md`](windows/README.md) |

Each guide walks you through the same five steps (Step 0 → Step 4):
getting the course files, installing Python, installing DuckDB /
Marimo / Pandas / Matplotlib, verifying everything in Marimo, and
installing Java + qStudio. Each also has its own troubleshooting guide
for common Day-1 problems.

**Set aside about an hour**, and do this **before the first class**.
