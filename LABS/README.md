# In-Class Labs

These are the in-class labs, one Marimo notebook per lab. Each lab is
posted after class.

* **Student** — the lab with blanks, as you saw it in class.
* **Instructor** — the same lab with the answers filled in.

## Open a Lab in Your Web Browser

Click an **Open in molab** button to run a lab in your web browser.
Nothing to install. Molab is a free service from the makers of Marimo.
