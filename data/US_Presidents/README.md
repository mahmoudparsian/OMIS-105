# US Presidents

A CSV of the US presidents, scraped from Wikipedia's
[List of presidents of the United States](https://en.wikipedia.org/wiki/List_of_presidents_of_the_United_States).

| File | Description |
|---|---|
| `us_presidents.csv` | 47 rows (one per president), columns: `number`, `portrait` (image URL), `name`, `date_of_birth`, `date_of_death`, `term`, `party`, `election`, `vice_president` |
| `us_presidents.html` | The raw source table, saved for reference |
