# Auto Insurance Data Story

## Project Overview
OMIS 105 teaching materials using an auto insurance dataset (~9,134 rows, 24 columns) to teach SQL queries via DuckDB in Jupyter notebooks.

## Files
- `auto_insurance.csv` — Raw dataset (9,134 rows including duplicates)
- `auto_insurance_db.duckdb` — Cleaned DuckDB database (generated by Notebook 1)
- `01_data_cleaning_and_db_creation.ipynb` — Notebook 1: CSV → clean DuckDB
- `02_sql_queries.ipynb` — Notebook 2: SQL teaching (simple → advanced)
- `util_plot.py` — Shared plotting utilities (matplotlib + seaborn)
- `jenks-natural-breaks-and-k-means-clustering.ipynb` — Reference notebook from Kaggle

## Database Schema
Single table: `insurance` with snake_case column names:
- customer, state, customer_lifetime_value, response, coverage, education
- effective_to_date, employmentstatus, gender, income, location_code
- marital_status, monthly_premium_auto, months_since_last_claim
- months_since_policy_inception, number_of_open_complaints, number_of_policies
- policy_type, policy, renew_offer_type, sales_channel, total_claim_amount
- vehicle_class, vehicle_size

## Conventions
- All SQL is written for DuckDB
- Column names are snake_case (no spaces)
- Plotting code lives in `util_plot.py`, imported into notebooks
- Each notebook cell: explain → SQL → result → plot (when applicable)
